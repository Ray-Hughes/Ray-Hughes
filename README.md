## Delphi, which you can install right now

<a href="https://ray-hughes.github.io/delphi/">

A project tracker with a knowledge graph that AI agents keep current themselves.
Projects hold tasks, memory notes and links. Claude Code and GitHub Copilot read
and write the same store over MCP, so what one agent works out survives into the
next session.

Eleven MCP tools, zero runtime dependencies, one local SQLite file, and an audit
log that makes every change reversible.

## A few things I believe

- **An invented answer is worse than a missing one.** Delphi's knowledge graph
  extracts deterministically rather than asking a model, because a missing node
  makes a query return less while a wrong node makes it return something false.
- **Undo should not be a second system.** Every write records the row as it was,
  so reversing a change replays stored state instead of guessing at it.
- **The tooling you leave behind is the deliverable.** The most useful thing I
  built on my current programme was not a feature, it was the shared config layer
  that stopped a team of engineers each inventing their own way of using AI.
